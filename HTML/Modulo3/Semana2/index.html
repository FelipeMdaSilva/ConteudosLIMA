Principais Categorias do HTML5:

Metadata Content - Flow Content - Sectioning Content - Heading Content - Phrasing Content - Embedded Content - Interactive Content

Metadata Content

<title> Informa o titulo
<meta> Definir codificação
<link> e <style> Importar CSS
<script> Configurar o comportamento da pagina (javascript)

Flow Content

Representa a maior parte dos elementos usados no body

<div> Caixa de divisão genérica, serve para agrupar "pedaços" de código.
<p> Para colocar paragráfos na minha página.
<section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.
<article> Conteúdo independente e completo por si só (faz sentido sozinho).
<img> Mostra uma imagem, foto, desenho, etc (não precisa de tag de fechamento).
<form> Criar formulários, o usuário poderá digitar dados, enviar mensagens ou fazer login.

Sectioning Content

Orgnaizar grandes áreas do documento

<Section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.
<Article> Conteúdo independente e completo por si só (faz sentido sozinho).
<Aside> Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia, etc).
<Nav> Agrupar os links de navegação

Heading Content

h1, h2, h3, h4, h5 e h6 => Para adicionar títulos e subtítulos
<hgroup> Serve para agrupar elementos de título, exemplo:

Aprenda HTML

Senai Americana

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> Um bloco genérico, não muda nada sozinho. Serve para agrupar pedaços de texto e aplicar CSS ou funções com javascript
<a> Cria um link para direcionar o usuário para outra página, utilizando o atributo href. Exemplo: Cliqe aqui para ir ao site do bitcoin
<strong> Deixar uma parte do texto em negrito
<em> Deixar uma parte do texto em itálico
<mark> Adiciona um marcador em uma parte do texto
<img> Mostra uma imagem, foto, desenho, etc. (Não precisa de tag de fechamento)

Embedded Content

<img> Mostra uma imagem, foto, desenho, etc. (Não precisa de tag de fechamento)
<video> Adicionar um vídeo direto no site (pode mostrar botões de play e pause)
<canvas> Criar uma tela em branco que poderá ser usada pelo javascript
<svg> Desenha gráficos baseados em vetores
<iframe> Coloca outra página inteira dentro do seu website (muito usado para adicionar mapas e vídeos de outras páginas)

Interactive Content

<a> Cria um link para direcionar o usuário para outra página, utilizando o atributo href
<button> Cria um botão clicável. Exemplo:
<input> Usado para receber dados. Dentre os dados aceitos estão:
type="text": campo de texto curto.
type="password": oculta os caracteres digitados.
type="email" ou type="number": valida dados específicos
type="checkbox" ou type="radio": caixas de marcação e escolha única.
*** type é uma tag que não precisa de fechamento
<select> Cria uma caixa de seleção em formato de lista suspensa (dropdown)
<textarea> Cria uma "caixa" com várias linhas, serve para textos longos, comentários, mensagens e biografrias.

Listas em HTML

Lista não ordenada (ul), exemplo:

  • Item 1
  • Item 2
  • Item 3

Lista Ordenada (ol), exemplo:

  1. Item 1
  2. Item 2
  3. Item 3
